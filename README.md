# Backend - Semana 5

## Descripción

API desarrollada con Node.js, Express y MongoDB para gestionar tareas y metas.

## Tecnologías utilizadas

- Node.js
- Express
- MongoDB Atlas
- Mongoose
- Thunder Client

## Funcionalidades

### Tasks
- Obtener tareas
- Agregar tareas
- Eliminar tareas

### Goals
- Obtener metas
- Agregar metas
- Eliminar metas

## Configuración

### Instalar dependencias

```bash
npm install
```

### Ejecutar servidor

```bash
npm start
```

## Variables de entorno

Crear un archivo `.env` con:

```env
MONGO_URI=tu_conexion_mongodb
```
